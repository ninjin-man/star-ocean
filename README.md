# Pixel Mask Part Editor v0.5

iPhoneで低解像度キャラクターの可視ピクセルを人がパーツ分解する、AI・OpenCV不使用の手動マスクツールです。

## 起動

`index.html` をブラウザで開き、画面上部の「PNG画像を選択」から画像を読み込みます。読込前も32×32の空キャンバスを表示します。承認済みのFF5バッツ戦闘待機16×24は動作確認用サンプルとして任意に表示できます。

## MVP機能

- 1ドットペン
- 同じRGBAでつながった領域の塗りつぶし
- 同色スポイト（上下左右に隣接する完全同色を、既存マスクに関係なく選択パーツへ一括統一）
- OpenCV.js 4.12をローカル同梱（外部通信不要）
- 完全同色・近似色・孤立領域・外周・Opening・Closingの選択式補助
- 黄色＝追加／選択候補、ピンク＝削除候補、水色＝外周
- プレビュー後の確定／取消。形態学処理は他パーツを上書きしない
- 4段階の作業導線（画像→パーツ→選び方→候補確定）
- 「色をまとめて」を標準操作にし、技術的なOpenCV項目は仕上げ補助へ収納
- 色許容値を同色／狭い／標準／広いの4プリセット化
- 未分類だけ選ぶ安全設定を標準ON
- 複数の離れた領域をタップして、1回でまとめて確定
- 未分類ピクセルの薄色表示、次の未分類への移動、進捗率表示
- 通常の連続色選択は軽量ローカル処理で即時実行し、OpenCV.jsは仕上げ補助を開いた時だけ起動
- 未分類へ戻す消しゴム
- パーツ取得
- 1ピクセル1パーツの排他的割当
- 未分類・割当済み・重複・再合成差の常時表示
- 元画像濃度、マスク、選択パーツ、グリッド表示切替
- Undo / Redo
- PNG読込（最大128×128）
- 読込前の空キャンバス、読込進捗、エラー理由表示
- localStorage自動保存
- source / assignment / recomposed / layers / JSONをZIP出力
- 1本指描画、2本指移動・ピンチ拡大

元画像は変更しません。未分類が残る場合、再合成差として同じ数を表示します。
